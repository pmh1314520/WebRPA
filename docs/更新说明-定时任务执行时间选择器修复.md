# 更新说明：定时任务「执行时间」选择器修复与重做

> 本文档面向需要在其它 WebRPA 分支/衍生版中同步此修复的开发者（或 AI 助手）。
> 内容自包含：问题现象、根因分析、全部改动文件与完整代码、验证方法。
> 对应版本：WebRPA 2.5.0，2026-07-20。

---

## 一、用户反馈的问题

1. **鼠标点击选不中**：计划任务（定时任务）创建/编辑对话框中，「执行时间」的时/分/秒下拉框用鼠标点击选项无法选中，**只能用键盘方向键 + 回车**选择。
2. **尺寸太小**：弹出的时/分/秒三个下拉框每个只有约 64px 宽，选项文本被截断成 "1..." "0..."，难以辨认和点击。

受影响位置（组件为共享组件，以下场景全部受影响）：

- 计划任务 → 时间触发 → 一次性执行 → 开始时间
- 计划任务 → 每日 / 每周 / 每月执行 → 执行时间
- 屏保弹幕对话框中的 `DateTimePicker`（同一文件内的日期+时间组合选择器）
- `DatePicker` 日历面板顶部的「年份/月份」下拉框（同样的点击 Bug，用户未报告但同根因）

---

## 二、根因分析（重要，决定修复方案）

相关文件：

- `frontend/src/components/ui/date-time-picker.tsx` —— DatePicker / TimePicker / DateTimePicker
- `frontend/src/components/ui/popover.tsx` —— **自研简化版 Popover（非 Radix Popover）**
- `frontend/src/components/ui/select-native.tsx` —— SelectNative（内部是 Radix Select，选项通过 Portal 渲染到 `document.body`）

### Bug 1：鼠标点击选不中（竞态卸载）

旧版 `TimePicker` 的面板 `TimePanel` 是**自研 Popover 里嵌套 3 个 SelectNative（Radix Select）**：

```
TimePicker
└─ Popover（自研，内联绝对定位）
   └─ PopoverContent
      └─ TimePanel
         ├─ SelectNative(时)   ← Radix Select，选项 Portal 到 body
         ├─ SelectNative(分)
         └─ SelectNative(秒)
```

自研 `PopoverContent` 的"点击外部关闭"逻辑是：

```tsx
document.addEventListener('mousedown', handleClickOutside)
// handleClickOutside: 若 event.target 不在 contentRef 内 → setOpen(false)
```

而 Radix Select 的下拉选项列表是 **Portal 渲染到 `document.body`** 的，DOM 上不在 `contentRef` 内。于是：

1. 用户鼠标按下（mousedown）某个"15 分"选项；
2. Popover 的 `handleClickOutside` 先触发，判定"点击在面板外"→ 关闭 Popover；
3. Popover 关闭导致 `TimePanel` 连同里面的 Radix Select **整棵卸载**；
4. 后续的 click / Radix 的选中事件失去目标，**选择动作丢失**。

键盘操作（方向键+回车）不触发 `mousedown`，所以能选中——这完全吻合用户"点击不能选择，只能按回车"的现象。

`DatePicker` 日历顶部的年/月 SelectNative 是同样的结构，同样中招。

### Bug 2：尺寸小

旧版三个 SelectNative 各自 `!w-[64px]`，选项文本 "00 时" 在触发器里被 truncate 成 "0..."。

### 附带发现的 Bug 3：英文界面下动态文本被"冻结"（修复过程中发现）

`frontend/src/lib/uiI18n.ts` 的运行时翻译层用 `WeakMap<Text, string>` 缓存每个文本节点的"原文"。旧逻辑：

```ts
if (!origText.has(node)) origText.set(node, node.nodeValue)   // 只在第一次缓存
const zh = origText.get(node)                                  // 之后永远用缓存翻译
```

当 React **原地更新**同一个文本节点（例如时间值 `08:00:00 → 11:00:00`、各类计数器），翻译层在英文模式下会把 React 刚写入的新值**回滚成旧缓存的译文**——表现为"选了时间但触发器上的数字不变"。中文模式不受影响（不翻译）。

## 四、具体改动

### 4.1 `date-time-picker.tsx` —— 重写时间面板

删除旧的 `TimePanel`（三个 SelectNative 的实现），替换为：

```tsx
// ---------------- 时间面板（滚动列直选，无嵌套下拉） ----------------
/**
 * 之前的实现是三个嵌套 SelectNative（Radix Select 会 Portal 到 body），
 * 与自绘 Popover 的「点击外部即关闭」冲突：鼠标点击下拉选项时整个面板被
 * mousedown 抢先卸载，导致「点击选不上、只能按回车」。
 * 现改为 antd 风格滚动列：每列直接点击数字即可选中，同时视觉尺寸更大。
 */
const clampTimePart = (raw: string | undefined, max: number) => {
  const n = Number(raw)
  if (!Number.isFinite(n)) return 0
  return Math.min(max, Math.max(0, Math.trunc(n)))
}

function TimeColumn({ label, count, value, onSelect, compact }: {
  label: string
  count: number
  value: number
  onSelect: (v: number) => void
  compact?: boolean
}) {
  const listRef = React.useRef<HTMLDivElement>(null)
  const didInit = React.useRef(false)

  // 首次打开：选中项直接定位到列表可视区中间；之后点击选择时平滑跟随
  React.useEffect(() => {
    const el = listRef.current
    if (!el) return
    const item = el.children[value] as HTMLElement | undefined
    if (!item) return
    const top = item.offsetTop - el.clientHeight / 2 + item.clientHeight / 2
    if (didInit.current) {
      if (typeof el.scrollTo === 'function') el.scrollTo({ top, behavior: 'smooth' })
      else el.scrollTop = top
    } else {
      el.scrollTop = top
      didInit.current = true
    }
  }, [value])

  return (
    <div className="flex flex-col items-stretch">
      <div className="text-center text-[11px] font-medium text-[hsl(var(--muted-foreground))] pb-1">{label}</div>
      <div
        ref={listRef}
        className={cn(
          'w-[60px] overflow-y-auto overscroll-contain scrollbar-thin rounded-[8px] border border-[hsl(var(--border))] bg-[hsl(var(--slate-50))] p-1 space-y-0.5',
          compact ? 'h-[128px]' : 'h-[192px]'
        )}
      >
        {Array.from({ length: count }, (_, i) => (
          <button
            key={i}
            type="button"
            onClick={() => onSelect(i)}
            className={cn(
              'w-full h-8 flex items-center justify-center rounded-[6px] text-[13.5px] tabular-nums transition-colors',
              i === value
                ? 'bg-[hsl(var(--brand-600))] text-white font-semibold shadow-sm'
                : 'text-[hsl(var(--slate-700))] hover:bg-[hsl(var(--brand-50))] hover:text-[hsl(var(--brand-700))]'
            )}
          >
            {pad(i)}
          </button>
        ))}
      </div>
    </div>
  )
}

function TimePanel({ value, withSeconds, onChange, compact }: { value: string; withSeconds?: boolean; onChange: (v: string) => void; compact?: boolean }) {
  const parts = (value || '').split(':')
  const hh = clampTimePart(parts[0], 23)
  const mm = clampTimePart(parts[1], 59)
  const ss = clampTimePart(parts[2], 59)
  const emit = (h: number, m: number, s: number) => {
    onChange(withSeconds ? `${pad(h)}:${pad(m)}:${pad(s)}` : `${pad(h)}:${pad(m)}`)
  }
  const setNow = () => {
    const now = new Date()
    emit(now.getHours(), now.getMinutes(), now.getSeconds())
  }
  return (
    <div className="select-none">
      <div className="flex items-start justify-center gap-2">
        <TimeColumn label="小时" count={24} value={hh} onSelect={(v) => emit(v, mm, ss)} compact={compact} />
        <TimeColumn label="分" count={60} value={mm} onSelect={(v) => emit(hh, v, ss)} compact={compact} />
        {withSeconds && (
          <TimeColumn label="秒" count={60} value={ss} onSelect={(v) => emit(hh, mm, v)} compact={compact} />
        )}
      </div>
      <div className="flex items-center justify-between gap-2 pt-2 mt-2 border-t border-[hsl(var(--border))]">
        <button
          type="button"
          onClick={setNow}
          className="px-2 py-1 rounded-[6px] text-[12px] text-[hsl(var(--brand-600))] hover:bg-[hsl(var(--brand-50))] transition-colors"
        >
          此刻
        </button>
        <span className="text-[13px] font-semibold tabular-nums text-[hsl(var(--foreground))] pr-1">
          {withSeconds ? `${pad(hh)}:${pad(mm)}:${pad(ss)}` : `${pad(hh)}:${pad(mm)}`}
        </span>
      </div>
    </div>
  )
}
```

要点：

- **每列是普通 `<button>` 列表**，点击即 `onSelect(i)`，没有任何 Portal/嵌套弹层，不可能再被外点逻辑误杀；
- 列高 192px（`DateTimePicker` 里传 `compact` 时 128px，防止"日历+时间"面板过高）、行高 32px、字号 13.5px —— 解决"尺寸太小"；
- 选中项高亮 + 打开时自动滚到可视区中间，点击后平滑跟随；
- 底部新增「此刻」按钮（一键填当前时间）和当前值实时预览；
- `clampTimePart` 对脏数据（如 `99:xx:70`）钳制到合法区间，杜绝 `NaN` 传播；
- `DateTimePicker` 中的 `TimePanel` 调用处改为 `<TimePanel ... compact />`。

同文件其它部分（`CalendarPanel`、`DatePicker`、`TimePicker`、`DateTimePicker` 的触发器）不变。

### 4.2 `popover.tsx` —— 外点关闭逻辑修复

三处改动（完整文件很短，建议直接对照重写）：

1. **Context 增加 `triggerRef`**，`PopoverTrigger` 把触发器 DOM 记录进去（asChild 分支通过 cloneElement 注入 ref，React 19 下 ref 作为普通 prop 传递）；
2. **`handleClickOutside` 三重豁免**：

```tsx
/** 判断事件目标是否位于 Radix Portal 弹层内（Select/Dropdown 等会 Portal 到 body） */
function isInRadixPortal(target: EventTarget | null): boolean {
  if (!(target instanceof Element)) return false
  return !!target.closest(
    '[data-radix-popper-content-wrapper], [data-radix-portal], [data-radix-select-viewport], [data-radix-menu-content]'
  )
}

const handleClickOutside = (event: MouseEvent) => {
  const target = event.target as Node
  // 1) 点在面板内：不关闭
  if (contentRef.current && contentRef.current.contains(target)) return
  // 2) 点在触发器上：交给触发器自身的 onClick 去切换开关，避免关了又开
  if (triggerRef.current && triggerRef.current.contains(target)) return
  // 3) 点在 Radix Portal 弹层内（面板中嵌套的下拉框选项等）：不关闭
  if (isInRadixPortal(event.target)) return
  setOpen(false)
}
```

3. **Escape 处理**：面板内嵌套的 Radix 弹层打开时，Esc 先关它，不关整个面板：

```tsx
const handleEscape = (event: KeyboardEvent) => {
  if (event.key !== 'Escape') return
  if (isInRadixPortal(event.target) || document.querySelector('[data-radix-popper-content-wrapper]')) return
  setOpen(false)
}
```

> 这一修复让所有「自研 Popover 内嵌 Radix 组件」的场景恢复正常（本项目中还有 `ColorField`、`CalendarPanel` 年/月下拉在用）。

### 4.3 `uiI18n.ts` —— 动态文本冻结修复

`translateTextNode` / `translateAttrs` 增加"最后写入值"记录，用来区分是我们写的译文还是 React 的原地更新：

```ts
// 新增两个 WeakMap
const lastWritten = new WeakMap<Text, string>()
const lastWrittenAttr = new WeakMap<Element, Record<string, string>>()

function translateTextNode(node: Text) {
  // ...原有 skip 判断不变...
  const cur = node.nodeValue
  if (!origText.has(node)) {
    origText.set(node, cur)
  } else if (cur !== lastWritten.get(node) && cur !== origText.get(node)) {
    // 当前值既不是我们上次写入的译文、也不是缓存原文 → React 原地更新了文本
    // （如时间值 08:00:00 → 10:00:00、计数器等），必须刷新缓存原文，
    // 否则会把 React 的新值回滚成旧缓存（英文模式下动态文本冻结）。
    origText.set(node, cur)
  }
  const zh = origText.get(node) as string
  const next = curLang === 'en' ? translateString(zh) : zh
  if (node.nodeValue !== next) node.nodeValue = next
  lastWritten.set(node, next)   // ← 每次翻译后记录
}
```

`translateAttrs` 同理（对每个属性维护 `lastWrittenAttr`，检测到属性值既非上次写入也非缓存原文时刷新缓存）。
