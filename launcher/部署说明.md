# WebRPA 启动器部署说明

启动器基于 Electron + Vue 3，界面由 Electron 内置 Chromium 渲染，无需系统 WebView2 运行时。

## 前置要求

- 项目根目录已内置 `nodejs`、`Python313`
- 无需 Rust / Tauri CLI

安装依赖：

```bash
cd launcher
..\nodejs\npm.cmd install
```

## 图标

启动器使用单个 `launcher/logo.ico` 作为应用与窗口图标。
如需重新生成，双击 `launcher/重新生成图标.bat`（基于内置 Python + Pillow 生成）。

## 构建应用

### 开发模式

```bash
cd launcher
开发模式.bat
```

或手动：

```bash
cd launcher
..\nodejs\npm.cmd run dev
```

### 生产构建

```bash
cd launcher
构建启动器.bat
```

或手动：

```bash
cd launcher
..\nodejs\npm.cmd run build
```

构建完成后，可执行文件位于：

- `launcher/release/WebRPA启动器.exe`（portable 单文件）

## 部署步骤

1. 安装依赖并运行构建脚本
2. 将生成的 `WebRPA启动器.exe` 复制到 WebRPA 项目根目录
3. 用户双击 `WebRPA启动器.exe` 即可启动

## 常见问题

### Q: 启动器无法找到 Python 或 Node.js

A: 确保 `Python313` 和 `nodejs` 文件夹在 WebRPA 项目根目录。

### Q: 服务启动失败

A: 检查 `backend/logs/backend.log` 与 `frontend/logs/frontend.log` 的错误信息，确保端口未被占用、配置文件正确。

### Q: 图标显示不正确

A: 确保 `launcher/logo.ico` 存在，可运行 `重新生成图标.bat` 重新生成。

## 更新版本

启动器版本只需修改 `launcher/package.json` 的 `"version"` 字段；
项目整体版本可运行根目录 `_update_version.ps1` 一键更新并打包。

## 自动更新功能

启动器内置版本检查：Electron 主进程 `electron/main.cjs` 中的 `checkUpdate` 会请求远程版本接口
（`https://hub.pmhs.top/api/version`），与本地版本比较后返回更新信息与下载链接。

## 技术栈

- 前端：Vue 3 + Vite
- 桌面框架：Electron
- 打包：electron-builder（portable）
- UI：原生 CSS（无第三方 UI 库）
- 进程管理：Node.js child_process
- 日志：文件写入（backend/logs、frontend/logs）
