# WebRPA 启动器 - 快速开始

启动器基于 Electron + Vue 3，界面由 Electron 内置的 Chromium 渲染，无需安装系统 WebView2 运行时。

## 前置要求

- 项目根目录已内置 `nodejs`、`Python313` 文件夹
- 无需安装 Rust / Visual Studio C++ 构建工具（Electron 不需要）

## 开发模式

方式一（推荐）：双击 `launcher/开发模式.bat`

方式二（手动）：

```bash
cd launcher
..\nodejs\npm.cmd install
..\nodejs\npm.cmd run dev
```

`npm run dev` 会并行启动 Vite 开发服务器（端口 1420）与 Electron 窗口，修改前端代码自动热重载。

## 构建生产版本

方式一（推荐）：双击 `launcher/构建启动器.bat`

方式二（手动）：

```bash
cd launcher
..\nodejs\npm.cmd run build
```

构建完成后，可执行文件位于：`launcher/release/WebRPA启动器.exe`（单文件 portable）。

## 使用启动器

1. 将构建好的 `WebRPA启动器.exe` 复制到 WebRPA 项目根目录
2. 双击运行
3. 点击"启动服务"按钮
4. 等待服务启动完成（约 5-10 秒）
5. 打开浏览器访问 WebRPA

## 功能说明

- 一键启动 / 停止前后端服务
- 服务状态监控、版本更新检测
- 系统托盘、最小化到托盘、开机自启、启动时自动隐藏
- 独立小助手 Agent 窗口（置顶、贴边自动隐藏）

## 常见问题

### Q1: 启动器无法启动

- 确保 `Python313` 文件夹存在于项目根目录
- 确保 `nodejs` 文件夹存在于项目根目录
- 确保 `WebRPAConfig.json` 配置文件存在

### Q2: 服务启动失败

查看日志目录中的错误信息：

- 后端日志：`backend/logs/backend.log`
- 前端日志：`frontend/logs/frontend.log`
- 端口被占用：修改 `WebRPAConfig.json` 中的端口号

### Q3: 图标显示异常

确保 `launcher/logo.ico` 存在；可双击 `launcher/重新生成图标.bat` 重新生成。

## 更新版本号

启动器版本号只需修改 `launcher/package.json` 的 `"version"` 字段。
项目统一版本可运行根目录的 `_update_version.ps1` 一键更新并打包。
